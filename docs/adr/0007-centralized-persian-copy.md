# ۷. تمرکز متن‌های فارسی در یک فایل

- **وضعیت:** پذیرفته‌شده
- **تاریخ:** ۱۴۰۵

## زمینه

در نسخهٔ قبلی، متن‌ها در `constants/messages.ts` بودند ولی کنارشان متن‌های
فارسی دیگری هم پراکنده بود: بخشی داخل `bot.controllers.ts`، بخشی در
`utils/format.ts`، و چند جا رشته‌های فارسی مستقیم داخل منطق نوشته شده بود.

پیامدش این بود که:

- برای یکدست‌کردن لحن، باید چند فایل را می‌گشتید.
- هیچ راهی نبود بفهمید یک متن کجا استفاده می‌شود.
- متن‌ها با نیم‌فاصلهٔ نادرست و «ي» و «ك» عربی نوشته شده بودند.
- برای خطاها دو روایت وجود داشت: پیام فنی انگلیسی و متن کاربر، که در عمل
  گاهی پیام فنی به کاربر نشان داده می‌شد.

## تصمیم

یک فایل `src/copy/fa.ts` که تمام متن‌های کاربر را در خود دارد، و یک قاعدهٔ
سخت: **هیچ رشتهٔ فارسی‌ای بیرون از این فایل نوشته نمی‌شود.**

ساختار فایل:

```ts
export const copy = {
  start: { welcome: (name: string) => `…` },
  menu: { … },
  reservation: { … },
  forgetCode: { … },
  autoReserve: { … },
  errors: { … },
};
```

- هر ورودی یک **تابع** است، حتی وقتی پارامتری ندارد. این باعث می‌شود امضای
  متن‌ها یکدست بماند و افزودن پارامتر بعداً تغییری در فراخوانی‌ها نخواهد.
- همهٔ مقادیر تزریق‌شده از `escapeHtml` می‌گذرند.
- `FOOTER` یک ثابت مستقل است، نه تابعی که به `copy` ارجاع بدهد (وگرنه تایپ
  آبجکت به خودش وابسته می‌شد).
- خطاها هم دو روایت دارند: `message` فنی برای لاگ و `userMessage` فارسی برای
  کاربر. کلاس پایهٔ `AppError` هر دو را حمل می‌کند و لایهٔ نمایش همیشه دومی
  را نشان می‌دهد.

## پیامدها

**مثبت**

- برای بازخوانی لحن کل ربات، یک فایل کافی است.
- جست‌وجوی یک عبارت، همهٔ کاربردهایش را نشان می‌دهد.
- نیم‌فاصله، اعداد فارسی، «گیومه» و «ی/ک» فارسی یک‌جا و یکدست رعایت می‌شوند.
- خطای فنی هرگز به کاربر نمی‌رسد؛ حتی یک خطای پیش‌بینی‌نشده هم در
  `reply.ts` به یک جملهٔ فارسی ترجمه می‌شود.

**منفی**

- برای یک متن کوتاه باید یک فایل دیگر را هم باز کنید.
- `copy/fa.ts` بزرگ است. اگر از چند صد خط گذشت، شکستنش به `copy/fa/` با یک
  فایل برای هر صفحه منطقی است.

**رعایت‌شده در نگارش**

- نیم‌فاصله در «می‌روم»، «نمی‌شود»، «کد‌ها».
- اعداد فارسی در متن، لاتین در کد.
- «گیومه» فارسی به‌جای `"`.
- بدون خط تیرهٔ بلند (em dash).
- لحن محاوره‌ای محترمانه: «می‌تونی» و «سر بزن»، نه رسمی خشک و نه خودمانی
  بی‌ادب.
